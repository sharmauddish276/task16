# Student Records

## Description

This project displays student records using HTML, CSS, and JavaScript. It includes a search box to search for students by name.

## Features

* Displays student name, marks, class, and address.
* Shows student details in card format.
* Uses the `map()` function to display student cards.
* Uses the `filter()` function to search students by name.
* Updates search results dynamically while typing.

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Open the project in VS Code.
2. Save the code in a file named `index.html`.
3. Open the file in any web browser.
4. Type a student's name in the search box to find the student.

## Conclusion

This project demonstrates the use of JavaScript arrays, objects, `map()`, and `filter()` to display and search student records.
